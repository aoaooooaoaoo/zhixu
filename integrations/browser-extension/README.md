# 知序 · 浏览器采集插件（Chrome / Edge）

> 这是“浏览器 Agent”的轻量替代方案：不自动登录、不爬全站，只在你正常浏览小红书时，把**当前打开的笔记**提取成结构化文本，发进知序收件箱。

## 为什么不做“服务端自动浏览小红书”

- 小红书需要登录、验证码、风控；服务端无头浏览器很难稳定，也容易触发账号风险；
- 自动登录/批量爬取不符合平台条款；
- 你真正需要的是“我正在看的这一篇，帮我存下来”，扩展用你已登录的浏览器最稳、最合规。

## 安装（开发者模式，1 分钟）

1. 打开 Chrome 或 Edge；
2. 地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）；
3. 打开右上角「开发者模式」；
4. 点「加载已解压的扩展程序」，选择本目录：
   `D:\桌面\教学agent\温酱\integrations\browser-extension`
5. 工具栏出现「知」图标即成功。

## 使用

1. 先启动知序：`D:\桌面\教学agent\温酱\app\server.py`（或 `启动知序.bat`）；
2. 在小红书打开一篇笔记详情页；
3. 点扩展图标 →「发送当前笔记到知序」；
4. 知序顶栏收件箱会出现一条「浏览器插件 · 小红书」；
5. 点「读取并归档」→ 正文已带入 →「理成知识卡片」。

也支持：

- 右键页面 →「发送当前页面到知序」；
- 快捷键 `Ctrl+Shift+Y`（Mac `⌘+Shift+Y`）；
- 任意网页也可以发送标题/描述（兜底提取）。

## 提取内容

| 字段 | 来源 |
|---|---|
| 标题 | `#detail-title` / `og:title` / 页面标题 |
| 正文 | `#detail-desc` / `.note-text` / `.note-content` / 兜底可见文本 |
| 作者 | `.author-wrapper .name` / `.username` 等 |
| 话题 | 正文里的 `#话题` |
| 图片 | `og:image` / 轮播图（仅记录 URL，不下载） |
| 来源 | 当前页面 URL |

> 小红书改版后 CSS 类名可能变化；如果提取不到正文，扩展会提示“请打开笔记详情页”，也可以把正文复制到知序手动粘贴。

## 安全与隐私

- 扩展只把数据发到 `http://127.0.0.1:8788`，不经过任何第三方服务器；
- 不读取 cookie、不保存密码、不自动登录；
- 只在你点击按钮/快捷键/右键时执行，不后台轮询；
- 建议只在个人电脑上加载，不要把知序收件箱直接暴露到公网（目前无鉴权，只有本机）。

```
└── icons/             # 16/32/48/128 图标
```

## 备选：书签工具（不装扩展）

如果不想装扩展，也可以在浏览器书签栏放一个书签脚本（bookmarklet），但跨域和提取能力受限；扩展是更稳的方案。
