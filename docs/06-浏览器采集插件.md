# 知序 · 浏览器采集插件（小红书）

> 用户问：能不能加一个浏览器 Agent，直接浏览小红书？
> 结论：**不做一个自动登录、自动爬全站的 Agent**；做一个**只采集你当前笔记页**的浏览器扩展，更稳、更合规，效果也更接近“我看到什么就能存什么”。

---

## 1. 为什么不用“服务端自动浏览”

| 方案 | 问题 |
|---|---|
| 服务端无头浏览器 + 登录态 | 小红书登录/验证码/风控强；无头浏览器容易被识别；账号有风险 |
| 自动扫码/存 cookie | 需要把登录态交给服务端；平台条款与安全风险高 |
| 全站爬取/批量采集 | 明确的违规风险，也不是用户真实需求 |
| **浏览器扩展（本方案）** | 用你本人已登录的浏览器，只读当前页面；点击才采集；不发 cookie、不自动登录 |

## 2. 工作方式

```
你在 Chrome/Edge 打开小红书笔记
        ↓ 点击「知」扩展 / 右键 / Ctrl+Shift+Y
content script 读取 DOM：标题、正文、作者、话题
        ↓ POST http://127.0.0.1:8788/api/inbox
知序收件箱出现「浏览器插件 · 小红书」
        ↓ 点「读取并归档」
正文直接填入 → AI 提炼成卡片
```

- 扩展只在**小红书域名**注入 content script；其他网页可用右键做通用标题/描述提取；
- 不读 cookie、不存密码、不后台轮询；
- 服务端只接收标题/正文/URL/作者，存本地 `app/data/inbox.json`。

## 3. 安装

1. 打开 Chrome `chrome://extensions`（Edge `edge://extensions`）；
2. 开启「开发者模式」；
3. 「加载已解压的扩展程序」→ 选择：
   `D:\桌面\教学agent\温酱\integrations\browser-extension`
4. 工具栏出现「知」图标。

## 4. 使用

1. 启动知序：`启动知序.bat` 或 `cd app && D:\python\python.exe server.py`；
2. 在小红书打开笔记详情页；
3. 点击扩展 →「发送当前笔记到知序」；
4. 知序顶栏收件箱出现条目 →「读取并归档」；
5. 检查正文 →「理成知识卡片」。

也支持右键菜单「发送当前页面到知序」、快捷键 `Ctrl+Shift+Y`。

## 5. 这次能解决你刚发的链接吗

你发的是 `https://xhslink.cn/...` 短链，服务端跟随后跳到小红书登录页，拿不到正文——这是平台限制。

**用浏览器扩展**：你在自己电脑的 Chrome/Edge 里打开这篇笔记（已登录小红书），点一下扩展，正文就会直接进知序，不再依赖服务端抓取。这是当前最可靠的路径。

## 6. 限制

- 小红书改版可能改 CSS 类名；提取不到时扩展会提示，仍可手动粘贴；
- 扩展是开发者模式加载，未上架商店；
- 只采集当前页，不做自动翻页/批量；
- 知序收件箱默认无鉴权，仅本机使用；
- 如果知序端口不是 8788，需要改 `background.js` 里的 `ZHIXU_URL`。

## 7. 文件
