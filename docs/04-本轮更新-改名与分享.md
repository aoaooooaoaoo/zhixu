# 知序 · 本轮更新（改名 / 链接分享 / QQ 收件箱）

> 对应原「温酱」MVP。产品名改为 **知序**；文件夹仍保留 `温酱`（避免移动用户目录），只改产品与界面文案。

## 1. 改名

- 品牌：温酱 → **知序**
- slogan：把刷到的碎片，**理成**自己的知识（原「熬成」）
- 界面：logo 字「知」、`KNOWLEDGE ORDER`、顶栏/页脚/弹窗/服务端提示全部切换
- 单文件：`docs/知序MVP-单页版.html`
- 启动：`启动知序.bat`
- **数据迁移**：localStorage 首次读取旧 key `wenjiang.mvp.v1`，自动写入新 key `zhixu.mvp.v1`，已有卡片不丢

## 2. 链接分享

### 2.1 链接读取

- 收集页新增 **读取链接**
- 服务端 `POST /api/resolve`：抓 `og:title/description` + 正文
- 小红书登录墙 → `blocked: true`，提示手动粘贴，**保留原链接**（不覆盖成验证码 URL）
- 防 SSRF：只允许 http/https，拒绝本机/内网/保留地址

### 2.2 PWA 分享目标

- `manifest.webmanifest` + `sw.js` + 192/512 图标
- `/share?url=...` 接收 Android Chrome 的分享
- 前端 boot 时读取 `?url/text/share`，自动填入并读取
- 限制：Android Chrome、HTTPS/localhost；iOS 不支持

### 2.3 QQ 收件箱

- 服务端 `/api/inbox`（GET/POST/DELETE），数据在 `app/data/inbox.json`
- 顶栏收件箱图标 + 未读数；收集页「来自分享的链接」面板；每 8 秒轮询
- 可选 token：`WJ_INBOX_TOKEN`（外部桥 POST 时带 `X-Inbox-Token`）
- 本地桥 `integrations/qq/qq_bridge.mjs`：Node 22+，连接 OneBot WebSocket，私聊带链接 → 投递收件箱
- 文档：`docs/03-链接分享与QQ接入.md` + `integrations/qq/README.md`
- **没有接管/代登录任何 QQ**；需要用户自备小号扫码，第三方协议有风控风险

### 2.4 浏览器采集插件（新增）

- Chrome/Edge Manifest V3 扩展：`integrations/browser-extension/`
- 在已登录的小红书笔记页点扩展，读取当前页标题/正文/作者/话题 → POST `/api/inbox`
- 服务端加了 CORS（供 `chrome-extension://` 调用）；正文已在收件箱里时直接填入，不再抓登录墙
- 安装与原理见 `docs/06-浏览器采集插件.md`
