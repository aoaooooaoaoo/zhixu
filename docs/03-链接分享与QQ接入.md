# 知序 · 链接分享与 QQ 接入（产品说明）

> 代码与操作细节见 [`../integrations/qq/README.md`](../integrations/qq/README.md)。
> 本文说明产品上怎么设计、边界在哪。

---

## 1. 四种进入方式

| 方式 | 使用场景 | 状态 |
|---|---|---|
| 粘贴文本 | 任何平台、最稳 | ✅ MVP |
| 粘贴链接 + 读取 | 电脑上看到公开网页 | ✅ 已做（公开网页；登录墙会提示） |
| 浏览器扩展 | 在已登录的小红书页面，一键采集当前笔记正文 | ✅ 新增（`integrations/browser-extension/`） |
| PWA Share Target | Android 手机上从小红书直接分享到知序 | ✅ manifest/sw 已做，需安装 + HTTPS/localhost |
| QQ 分享收件箱 | 手机上先分享给 QQ 小号，再在知序归档 | ✅ 桥已提供，需自备 QQ 小号 + NapCat |

### 1.1 链接读取

- 服务端 `POST /api/resolve` 抓 `og:title/og:description` + 正文；
- 只接受 http/https，拒绝本机/内网（SSRF 防护）；
- 小红书等登录墙页面会返回 `blocked: true`，前端提示「请粘贴文字」，**原链接保留**为来源；
- 正文填入后可编辑，AI 只基于你确认的文本提炼。

### 1.2 PWA 分享

`manifest.webmanifest` 声明：

```json
"share_target": {
  "action": "/share",
  "method": "GET",
  "params": { "title": "title", "text": "text", "url": "url" }
}
```

用户在 Android Chrome 安装知序后，小红书分享面板会出现「知序」；打开时 URL 带 `?url=...`，前端自动读取并填入。iOS Safari 不支持；局域网 http 也可能无法安装，正式使用建议 HTTPS。

### 1.3 QQ 收件箱

```
小红书 → 分享/复制链接 → 私聊发给 QQ 小号
        → 本地 OneBot 桥 POST /api/inbox
        → 知序顶栏出现收件箱数字 → 读取并归档
```

- 服务端 `GET/POST/DELETE /api/inbox`，数据存 `app/data/inbox.json`；
- 前端每 8 秒轮询，顶栏收件箱 + 收集页面板；
- 桥只处理私聊、可设用户白名单，避免群聊刷屏；
- 可选 `QQ_REPLY=1` 回执「已收到」。

## 2. 为什么不做“全自动接管 QQ”

用户问过「能不能接管一个新建的 QQ 来收链接」。答案是：

- **技术可行**：OneBot 生态（NapCat / Lagrange / LLOneBot）+ 本地桥，能把私聊链接转成 HTTP；
- **但我不做代登录**：需要你本人扫码/验证；我没有也不应索取账号密码；
- **风险**：第三方协议不符合腾讯官方协议，可能被限制/封号；只能用小号，不能保证稳定；
- **合规**：只处理你主动发来的链接；不抓取私密内容、不自动加好友、不自动发广告。

所以产品把它设计成**可选、本地、自担风险**的插件，而不是默认能力。不用 QQ 也完全可以使用知序。

---

## 3. 安全设计

| 风险 | 处理 |
|---|---|
| SSRF（让服务端读内网） | 只允许 http/https；解析 IP 后拒绝 private/loopback/link-local |
| 收件箱被公网乱投 | 默认只绑 127.0.0.1；可选 `WJ_INBOX_TOKEN`；QQ 桥只在本地 |
| QQ 账号风控 | 只支持小号、私聊、白名单、低频；文档明确风险 |
| 抓取失败 | 明确提示，保留原链接，正文可手改 |
| 链接失效 | 卡片保留标题/博主/金句，链接只作参考 |

---

## 4. 已知限制

- 小红书正文抓取不稳定（登录/验证码），当前以「提示 + 手动粘贴」兜底；
- PWA 分享目标依赖浏览器/HTTPS，桌面端用「读取链接」；
- QQ 桥依赖 NapCat 版本与 QQNT，协议升级可能失效；
- QQ 真机扫码/消息链路需要用户提供小号并本人扫码；桥的提取/投递逻辑已有本地单测；
- 收件箱没有多用户/权限，只是本机单人工具；
- 不保存网页快照，原帖删除后只剩卡片与来源文字。

---

## 5. 后续

- 浏览器扩展：一键把当前页发给知序（比复制粘贴更短）；
- 链接快照：抓取时保存标题/关键段落，防链接失效；
- 多端收件箱：服务端数据库 + 登录；
- 队列消费：一次导入多条，自动去重/合并后再确认。
