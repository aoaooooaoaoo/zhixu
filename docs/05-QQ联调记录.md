## 1. 安装位置

| 组件 | 路径 / 端口 |
|---|---|
| NapCat + 独立 QQ（OneKey 安装） | `D:\NapCat`（**必须是 ASCII 路径**；中文路径会导致启动失败） |
| NapCat WebUI | `http://127.0.0.1:6099/webui/`（token 在 `D:\NapCat\qqdata\NapCat\config\webui.json`） |
| OneBot 11 WebSocket | `ws://127.0.0.1:3001`（NapCat「网络配置 → Websocket服务器」里启用） |
| 知序 | `http://127.0.0.1:8788` |
| 分享收件箱 | `app/data/inbox.json` |
| QQ 桥 | `integrations/qq/qq_bridge.mjs`（当前已连接 OneBot） |

> 独立 QQ 与桌面版 `D:\QQ` 互不影响：NapCat 用 `NAPCAT_QQ_DATA_DIR=D:\NapCat\qqdata` 隔离数据目录；没有改注册表，也没有动桌面版 QQ 的文件。

## 2. 启动顺序（重启机器后）

1. **NapCat**：双击 `D:\NapCat\start-zhixu-napcat.bat`（会请求管理员 UAC；必须点「是」）。
2. 浏览器打开 `http://127.0.0.1:6099/webui/`；如果未登录，用新 QQ 小号**扫码登录**（WebUI → 扫码登录）。
3. **知序**：双击 `启动知序.bat`，或：
   ```powershell
   cd "D:\桌面\教学agent\温酱\app"
   D:\python\python.exe server.py
   ```
4. **QQ 桥**：双击 `integrations\qq\start-bridge.bat`（自动从 NapCat 配置读端口/token），或手动：
   ```powershell
   cd "D:\桌面\教学agent\温酱\integrations\qq"
   $env:QQ_WS_URL="ws://127.0.0.1:3001"
   $env:QQ_ACCESS_TOKEN="<NapCat 里配置的 token>"
   $env:ZHIXU_INBOX_URL="http://127.0.0.1:8788/api/inbox"
   $env:QQ_REPLY="1"
   node qq_bridge.mjs
   ```
5. 主 QQ 给小号私聊一条链接 → 知序顶栏收件箱出现数字 →「读取并归档」。

## 3. 本次踩坑与结论
