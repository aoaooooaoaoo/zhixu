## 1. 三分钟上手

1. 打开网页，点顶部 **「收集」**
2. 把一段文字粘进大文本框（或点「粘贴文本」）
3. 点右下角 **「理成知识卡片」**
4. 等 5–15 秒，AI 会生成一张卡片：标题 / 一句话结论 / 3–4 条要点 / 标签 / 分类 / 主题
5. 点 **「确认归档」**，卡片进入「知识库」
6. 重复几次后，去 **「思维导图」** 看你的知识树

> 想先体验？点「放入示例笔记」，会有一张示例卡片。

## 3. 四种内容收集方式

### 3.1 直接粘贴文字（最稳）

适用：所有平台、所有情况。
1. 在来源 App 里复制文字
2. 粘贴到「收集」的大框
3. 链接可选填（填了会显示在卡片来源里）
4. 点「理成知识卡片」

### 3.2 贴链接自动抓正文

适用：公众号、豆瓣、简书、B站、掘金、CSDN、少数派、36氪、GitHub、普通网页。
1. 把链接填进「帖子链接」
2. 点 **「读取链接」**
3. 正文自动填入大框 → 点「理成知识卡片」

> 小红书/知乎/微博/抖音有登录墙，服务器抓不到；
> 需要先在**电脑上开本地抓取助手**（见第 7 节），网页会自动优先用它。

### 3.3 批量导入（一次抓一批）

适用：小红书（已登录助手时）、知乎。
1. 点「批量导入」
2. 选站点、填关键词、选排序（综合/最热/最新）、选条数（5/10/20）
3. 点「搜索」→ 勾选想要的 → 点「导入选中」
4. 系统会逐条：抓正文 → AI 提炼 → 入库（会跳过重复链接）

> 每条之间有 1.5–2.5 秒限速，防止小红书风控。

### 3.4 抓评论（补充社区观点）

1. 小红书链接填进「帖子链接」
2. 点 **「抓评论」**（需要本地助手已登录）
3. 弹窗按点赞排序显示评论 → 点「并入正文」
4. 评论会拼到正文后面，再点「理成知识卡片」，AI 会一起参考

## 3.5 自动抓取（网页里可视化调整）

打开 **齿轮 → 自动抓取 → 打开面板**，所有配置都在面板里改，不用碰服务器：

| 面板项 | 说明 |
|---|---|
| **关键词** | 输入关键词点「添加」，服务器就按关键词抓新闻（Bing 新闻 RSS，失败自动切 Google）；点词后面的 × 删除 |
| **抓取对象** | 选 RSS 或「固定链接」，填 `https://...` 点「添加」；适合你常看的博客/网页 |
| **运行时间** | 每天几点跑（默认 08:00），改完点「保存配置」 |
| **启用自动抓取** | 勾掉就暂停，不影响已抓内容 |
| **保存配置** | 改完必须点这个才生效 |
| **立即运行一次** | 马上抓一次（约 30–90 秒），结果进「收件箱」 |
| **上次/下次运行** | 面板顶部实时显示上次结果和下次时间 |

流程：抓取 → 只挑新内容 → AI 提炼成卡片 → 进 **收件箱** → 你点「读取并归档」入库。

> 需要先登录账号（配置存在服务器，按账号校验）。
> 小红书/知乎**不能**加进来（服务器没有登录态），它们仍需要本地抓取助手。

**推送（可选）**：服务器配置里填了 Qmsg 酱 key 后会把汇总推到 QQ；目前提示「未绑定机器人」，需要先在 <https://qmsg.zendee.cn/> 控制台扫码绑定机器人。

## 4. 知识库

- 左侧是 **分类树**（学习与效率 / 护肤与美妆 / 健康与生活…），点分类筛选
- 顶部可 **搜索** 标题/要点/标签/来源
- 右上角可切换排序（最新/最早/标题）和 **导入/导出 JSON**
- 卡片上显示：分类 › 主题、一句话摘要、要点、标签、来源、日期

**导出/导入**：用于换设备、备份。设置（齿轮）里也有同样入口。

## 4.5 分类管理（自定义 + AI 归纳）

打开右上角 **齿轮 → 设置**：

| 能力 | 怎么用 |
|---|---|
| **新增分类** | 「分类管理」输入框填名字（≤12 字）→ 点「添加」 |
| **重命名** | 自定义分类后面的「改」→ 输入新名字（会同步更新该分类下所有卡片） |
| **删除** | 自定义分类后面的「×」→ 该分类下卡片归到「未分类」 |
| **AI 自动新建分类** | 每次提炼时会把你现有的分类清单交给 AI；都放不进去时，AI 自动新建一个贴切的分类并登记（会提示「AI 自动新建了分类」） |
| **AI 整理分类** | 点「开始整理」：把整个知识库交给 AI 重新归类；能复用就复用，不够用自动新建（适合攒了很多卡片后重新梳理） |

说明：
- 系统预置的 10 个分类**不可删除**
- 分类名上限 12 字
- 「AI 整理分类」会修改卡片分类，建议先「导出 JSON」备份
- 实测：宠物类内容 → 新建「宠物养护」；汽车类 → 新建「汽车保养」；护肤/学习类会复用已有分类

## 5. 思维导图

- 自动按「分类 → 主题 → 卡片」生成树
- 节点名称用 **核心短语**（不是长标题），合并的卡片显示为「标签 ×N」
- 可拖拽、缩放、导出 SVG/PNG
- 卡片越多，导图越有用（建议先攒 10 张以上）

## 6. 问知识库（AI 问答）

1. 知识库页点 **「问知识库」**
2. 输入问题，例如：
   - 「我存的西安交大相关内容里，有哪些生活经验？」
   - 「关于早C晚A我记了哪些注意事项？」
3. 系统会挑最多 6 张最相关的卡片，只根据卡片回答，并标注「卡片标题」引用
4. 卡片里没有的内容，它会直说「没有找到」，不会编造

> 这是「检索增强」问答：答案质量取决于你存了多少卡片。

## 7. 本地抓取助手（小红书/知乎必看）

**为什么需要它**：小红书/知乎有登录墙，服务器抓不到；助手在你自己的电脑上用一个独立浏览器登录，所以能读到。

### 启动
```
双击 D:\桌面\教学agent\温酱\integrations\xhs\start-xhs-helper.bat
```
- 首次会弹一个独立 Edge 窗口，在里面登录小红书/知乎
- 登录一次，之后一直有效（登录态保存在本地 `.profile`）

### 用法
- 助手开着时，网页上的「读取链接」「抓评论」「批量导入」会自动优先走本地助手
- 网页底部会显示「🔓 登录窗口可读」，说明助手已连接

### 注意
- 只在**运行助手的这台电脑**有效；手机上无法使用
- 浏览器标签页要**在前台**（后台会被 Chrome 节流）
- 个人整理用途，**不要高频批量抓**，避免账号风控

## 8. 账号与云同步

### 注册/登录
1. 点右上角人像 → 填用户名（3–24 位）+ 密码（≥6 位）→ 注册
2. 登录状态保存在当前浏览器；换设备用同一账号登录

### 绑定接收 QQ（可选）
- 在账号弹窗里填 QQ 号 → 保存
- 作用：QQ 机器人转发内容时，可以**一对一**把结果发到这个 QQ（需要本机跑 QQ 桥接，见第 9 节）

### 云同步
1. 登录后，知识库页点 **「云同步」**
2. **上传到云端**：用当前数据覆盖云端
3. **从云端合并**：把云端卡片补进本地（按 id 去重，不删本地）

> ⚠️ 数据存在服务器 `/opt/zhixu/data/`，按账号隔离。
> 同步不会自动发生，需要手动点。

## 11. 常见问题（FAQ）

**Q1：网页打不开 / 一直转圈？**
- 确认用的是 `http://47.86.32.77:8080/`（带 8080）
- 换 Chrome/Edge 试试；公司网络可能限制 8080
- 检查服务器是否在线：浏览器打开 `/api/health` 应返回 JSON

**Q2：提示「AI 未连接」或提炼很慢？**
- 服务器 AI 走星火接口，首次响应 10–20 秒属正常
- 刷新页面看右上角状态灯
- 如果持续失败，联系管理员检查服务器 `.env`

**Q3：小红书链接读不到？**
- 需要本机开抓取助手并登录（第 7 节）
- 手机上无法使用，请改用「粘贴文字」

**Q4：批量导入搜不到结果？**
- 小红书搜索**必须登录**，先点「登录窗口」登录
- 知乎搜索同理
- 关键词换成更常见的词试试

**Q5：卡片重复了怎么办？**
- 批量导入会自动跳过重复 URL；手动粘贴的不会自动去重
- 知识库里点卡片可以删除

**Q6：换电脑后数据还在吗？**
- 网页版数据在浏览器本地（localStorage），换浏览器就没了
- 解决：登录账号 → 云同步 → 新设备登录 → 从云端合并

**Q7：同一个 AI 功能被限制？**
- 服务器对每个 IP 限制 **每小时 60 次** AI 调用（防滥用）
- 超了等一小时，或让管理员调大

**Q8：数据安全吗？**
- 数据在你自己（或你同学）的服务器上，不经过第三方
- 页面是 HTTP，**不要在里面存密码、身份证等敏感信息**
- 服务器 root 只能通过密钥登录（`C:\Users\shiyi\.ssh\zhixu_ali`）

## 12. 当前限制（先说清楚）

| 限制 | 说明 |
|---|---|
| 无 HTTPS | 只有 IP，没有证书；浏览器不会显示锁标 |
| 带宽 1Mbps | 约 128KB/s，个人用够，多人同时用会慢 |
| 内存 512MiB | 只能跑轻量服务，不能装大软件（dnf 会被 OOM 杀） |
| 抓取依赖本地助手 | 服务器端读不到小红书/知乎登录内容 |
| 手机端 | 能打开网页，但抓取/批量导入不可用 |
| 无自动同步 | 云同步要手动点 |

## 13. 管理员维护（服务器）

### 常用命令（SSH，用密钥）
```powershell
ssh -i "$env:USERPROFILE\.ssh\zhixu_ali" root@47.86.32.77
```

| 操作 | 命令 |
|---|---|
| 查看状态 | `systemctl status zhixu` |
| 重启 | `systemctl restart zhixu` |
| 看日志 | `journalctl -u zhixu -n 100 --no-pager` |
| 改配置 | 编辑 `/opt/zhixu/.env` 后重启 |
| 数据目录 | `/opt/zhixu/data/`（备份这个目录） |
| 程序目录 | `/opt/zhixu`（dist + functions + server.mjs） |
| 端口 | 80 与 8080（Node 直接监听，无 nginx） |

### 更新代码
1. 本机改完 → `node web/build.js --clean`
2. 重新打包上传（见项目 `deploy/vps/`）
3. 服务器 `systemctl restart zhixu`

### 备份数据
```bash
tar -czf /root/zhixu-data-$(date +%F).tar.gz -C /opt/zhixu data
```
