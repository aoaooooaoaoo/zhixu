## 二、简介（120 字以内，直接复制）

```
知序是一款笔记整理工具：把刷到的文字或链接粘贴进来，自动提炼成带标题、摘要、要点、标签和来源的知识卡片，按分类与主题归档，并可生成可交互的思维导图。数据默认只保存在你的手机本地，支持导出备份与导入恢复。
```

## 三、功能描述（提交审核时填，**不要出现「AI 生成」字样**）

```
【功能页面】
首页：pages/collect/index（收集）
页面二：pages/library/index（知识库）
页面三：pages/map/index（思维导图）

【功能说明】
1. 收集：用户主动粘贴文字或链接，工具按内置规则提炼成结构化卡片（标题/摘要/要点/标签/来源），用户可逐项修改后保存。
2. 知识库：按「分类 → 主题 → 卡片」三级归档，支持关键词搜索、排序、删除，支持导出/导入 JSON 备份。
3. 思维导图：把某一分类下的主题与卡片渲染成树状导图，支持拖拽平移与双指缩放；相似的卡片会合并为一个节点，并展示来源与差异。

【数据说明】
不采集手机号、位置、通讯录等个人信息；卡片数据仅保存在用户设备本地（wx.setStorageSync）。
读取剪贴板、写入相册均只在用户主动点击「导入」「导出图片」时发生。
```

## 四、用户隐私保护指引（后台逐项填报用）

**收集的信息类型：**

| 声明项 | 填写内容 |
|---|---|
| 剪贴板 | 仅在用户点击「导出」「导入」时读写，用于备份/恢复用户自己的卡片数据；不保存、不上传 |
| 相册（仅写入） | 仅在用户点击「导出图片」时把思维导图保存到相册 |
| 其他个人信息 | 不收集 |

**隐私政策正文（可放「隐私说明」文本框）：**

```
知序（以下简称"本小程序"）尊重并保护你的个人信息。

一、我们收集什么
本小程序不收集你的手机号、位置、通讯录、相册内容等个人信息。你创建的卡片数据仅保存在你所使用设备的本地存储中。

二、我们如何使用剪贴板
当你主动点击「导出」或「导入」时，本小程序会读取或写入系统剪贴板，仅用于传输你自己的卡片备份 JSON。剪贴板内容不会被上传到任何服务器。

三、我们如何使用相册
当你主动点击「导出图片」时，本小程序会把当前思维导图保存到你的相册；不会读取你相册中的其他内容。

四、数据存储与删除
卡片数据默认只存在你的设备本地。你可以随时在「知识库 → 导出」备份，或删除单张卡片；卸载小程序即清除全部本地数据。

五、第三方共享
本小程序不向任何第三方共享、转让你的个人信息。

六、联系我们
如对本隐私政策有疑问，可通过小程序「意见反馈」联系我们。
```

## 七、⚠️ 关于 AI 的实话

微信对「生成式 AI / AIGC」类目要求提供算法备案或与持证方合作，**个人主体基本拿不到**。
所以上线策略是：

1. **首版**：只上「本地规则提炼」（纯离线、不调用任何模型、不联网生成），类目报「工具 → 效率」→ 可过审
2. **自己用**：可以把 AppID 加白名单，在开发版/体验版里开启云开发 AI（`USE_CLOUD: true`），扫码就能用，不影响正式版
3. **将来**：主体升级为企业 / 拿到资质后，再切回云端 AI 并更新类目

这样既不耽误上线，也不丢掉 AI 能力。

## 八、上线后的操作

1. 公众平台 → 版本管理 → 开发版本 → 提交审核
2. 审核通过（一般 1–7 天）→ 点「发布」
3. 发布后在微信搜一搜「知序」即可找到；把小程序码保存下来分享
4. 后续改版：`node scripts/upload.js --version 1.0.1 --desc "修复…"` → 再提交审核
