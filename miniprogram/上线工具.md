# 上线工具包 · 怎么用

> 目标：把你的手工操作压到最少。能自动化的我已经做成脚本，剩下只有三件必须实名的事。
> 需要填的文字材料在 [`审核材料包.md`](./审核材料包.md)，全流程在 [`部署指南.md`](./部署指南.md)。

## 0. 先认清：哪些必须你做

| 步骤 | 为什么只能你做 | 耗时 |
|---|---|---|
| ① 注册小程序拿 AppID | 绑你的身份证 + 本人微信验证 | 10 分钟 |
| ② **小程序备案** | 通信管理局审核，绑主体身份 | **1–20 个工作日（最慢，先启动）** |
| ③ 提交审核 + 点发布 | 绑你的管理员微信号 | 1–7 天 |

> ⚠️ 顺序建议：**注册完立刻提交备案**，因为备案最慢；备案审核期间我们并行把代码、材料全部准备好，不浪费时间。

## 1. 工具清单

| 工具 | 命令 | 干什么 |
|---|---|---|
| 上线预检 | `node scripts/doctor.js` | 一次查出 AppID/云配置/语法/包体积/密钥泄露等 10 类问题，告诉你下一步 |
| 一键填配置 | `node scripts/setup.js --appid wx... --env zhixu-xxx` | 写 AppID、开云环境，自动备份原文件 |
| 上传开发版 | `node scripts/upload.js --version 1.0.0 --desc "首个版本"` | 走官方 CI 上传，**不用开开发者工具** |
| 生成预览码 | `node scripts/upload.js --preview` | 生成 `preview-1.0.0.png`，微信扫码真机试 |
| 只验证参数 | `node scripts/upload.js --dry` | 不上传，只检查 AppID/密钥/版本号 |
| 看当前配置 | `node scripts/setup.js --list` | 显示 AppID、云环境、当前模式 |

所有脚本都是**只读或带备份**的：`setup.js` 改文件前会生成 `xxx.bak-时间戳`。

## 2. 完整操作流（按顺序复制粘贴）

在 PowerShell 里：

```powershell
cd "D:\桌面\教学agent\温酱\miniprogram"

# ① 预检，看现在缺什么
node scripts/doctor.js

# ② 拿到 AppID 后填进去
node scripts/setup.js --appid wx1234567890abcdef

# ③（可选）开通云开发、要接真 AI 时填环境 ID
node scripts/setup.js --env zhixu-prod-8gxxxxxx

# ④ 再预检一次，应该没有 ❌
node scripts/doctor.js

# ⑤ 装一次性 CI 工具（约 30MB，只装到项目本地）
npm i miniprogram-ci --no-save

# ⑥ 生成预览二维码，微信扫码真机验收
node scripts/upload.js --preview

# ⑦ 验收没问题，上传开发版
node scripts/upload.js --version 1.0.0 --desc "知序首个版本"
```

然后去公众平台点「提交审核」→ 通过后「发布」。

## 6. 常见卡点速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `doctor.js` 报 AppID 还是 touristappid | 没填真实 AppID | `node scripts/setup.js --appid wx...` |
| 上传报 IP 白名单 | 代码上传密钥开了 IP 限制 | 后台关闭白名单，或把本机公网 IP 加进去 |
| 上传报 key 无效 | 密钥文件失效/路径错 | 重新下载 `private.wxXXXX.key` |
| 云函数调用总降级本地 | 云函数超时 3 秒不够 | 控制台把 analyze 超时改 60 秒 |
| 审核被驳回「AI 无资质」 | 首版开了云 AI | `node scripts/setup.js --local` 切回纯本地，重新上传 |
| 真机白屏 | 云开发没开通但 `USE_CLOUD: true` | 同上切回 local，或先开通云开发 |
