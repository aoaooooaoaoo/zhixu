# 知序 · 微信小程序部署指南

> 这份文档对应 `miniprogram/` 目录下的工程。目标：把一个能跑的小程序从「本地代码」推到「微信里能搜到、能打开」。
>
> **先说结论**：代码我已经全部做完，自动化工具也做好了（预检 / 填配置 / 上传 / 备案材料）。
> 只有三件事必须你本人操作 —— 注册账号、备案、点发布，它们绑定了你的身份和微信账号。
>
> 👉 想最快上手看 [`上线工具.md`](./上线工具.md)；要填的文字照抄 [`审核材料包.md`](./审核材料包.md)。

---

## 0. 先认清三道硬门槛

| 门槛 | 说明 | 谁来做 |
|---|---|---|
| **小程序账号（AppID）** | 没有 AppID 连真机预览都做不了 | 你（10 分钟） |
| **小程序备案** | 2023-09-01 起，新小程序**必须完成备案才能发布**，个人主体也能备 | 你（提交后等 1–20 个工作日） |
| **审核类目 / AIGC 资质** | 含「AI 生成内容」的小程序，微信要求相应资质；个人主体过审风险高 | 你决策，我给规避方案 |

> ⚠️ 关于第 3 条，实话实说：知序的核心是「AI 把笔记提炼成卡片」。微信对 AIGC 类目审得很严，**个人主体大概率拿不到 AI 类目资质**。
> 规避方案（推荐）：首版把「本地规则提炼」作为主功能上线（完全离线、不涉及生成式 AI），类目选 **工具 → 效率 / 笔记**；云函数 AI 只在**开发版/体验版**里给自己用，等主体升级为企业或拿到资质再切正式版。

## 1. 注册小程序，拿 AppID（你操作）

1. 打开 <https://mp.weixin.qq.com> → 右上角「立即注册」→ 选 **小程序**
2. 用一个**没注册过公众号/小程序的邮箱**激活
3. 主体类型选 **个人**，填身份证 + 管理员手机 + 微信扫码验证
4. 进入后台 → 左侧「开发」→「开发管理」→「开发设置」→ 复制 **AppID（小程序ID）**

拿到后，把 AppID 填到这两个地方：

- `miniprogram/project.config.json` → `"appid": "wx1234567890abcdef"`
- （可选）`project.private.config.json` 会被开发者工具自动生成，不用管

---

## 2. 用开发者工具打开项目（我可以帮你用 CLI 打开）

本机已装微信开发者工具：`C:\Program Files (x86)\Tencent\微信web开发者工具`

```powershell
# 导入项目（把 appid 换成你的）
& "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" open --project "D:\桌面\教学agent\温酱\miniprogram"
```

打开后：
- 顶部如果提示 AppID 不合法，把 `project.config.json` 里的 `touristappid` 换成你的 AppID
- 「详情 → 本地设置」勾选 **不校验合法域名**（云函数调用不受影响，但本地调试更省事）

---

## 3. 开通云开发（你操作，1 分钟）

1. 开发者工具顶部工具栏点 **「云开发」** 按钮
2. 开通 → 新建环境，环境名随便（如 `zhixu-prod`），套餐选**基础版**（有免费额度，超出按量计费，以控制台为准）
3. 记下 **环境 ID**（形如 `zhixu-prod-8gxxxxxx`）

填到 `miniprogram/miniprogram/config.js`：

```js
CLOUD_ENV: 'zhixu-prod-8gxxxxxx',
USE_CLOUD: true,
```

---

## 4. 部署云函数（你点三下）

在开发者工具左侧文件树：

1. 右键 `cloudfunctions/analyze` → **上传并部署：云端安装依赖**
2. 右键 `cloudfunctions/resolve` → 同上
3. 右键 `cloudfunctions/inbox` → 同上

> 云函数里的 LLM key 用「云开发控制台 → 云函数 → 配置 → 环境变量」填：
> `WJ_LLM_API_KEY` / `WJ_LLM_BASE_URL` / `WJ_LLM_MODEL`（和网页版 `app/.env.example` 完全一致）
> **key 永远不要写进小程序前端代码。**
>
> ⚠️ **必做**：云函数默认超时 3 秒，模型根本来不及返回。部署后到「云开发控制台 → 云函数 → analyze → 配置」把**超时时间改成 60 秒**，否则每次都会降级成本地规则。
> 同一处可以改 `resolve` 的超时（建议 20 秒）。

## 5. 建数据库集合（你操作，2 分钟）

「云开发控制台 → 数据库」新建两个集合：

| 集合名 | 权限 |
|---|---|
| `cards` | 仅创建者可读写 |
| `inbox` | 仅创建者可读写 |

字段由代码自动写入，不用手建索引（数据量大再加 `createdAt` 索引）。

## 6. 小程序备案（你操作，耗时最长）

开发者工具右上角「上传」之前或之后都可以，但**不备案无法发布**。

路径：微信公众平台 → 左侧「设置」→「基本设置」→「小程序备案」→ 填写：
- 主体信息（身份证、手机、邮箱、地址）
- 小程序信息（名称「知序」、服务内容选「工具-效率」之类、头像、简介）
- 管理员人脸核验

提交后由**通信管理局**审核，一般 1–20 个工作日。期间小程序可以上传体验版、自己扫码用，只是不能正式发布。

---

## 7. 上传 → 提交审核 → 发布（你操作）

**上传**：开发者工具右上角「上传」→ 填版本号 `1.0.0` + 备注 → 确定。

**提交审核**：公众平台 → 「版本管理」→ 开发版本 → 「提交审核」：
- 类目：**工具 → 效率**（或「教育 → 学习」）
- 页面路径：`pages/collect/index`（首页）
- 功能描述：**注意措辞** —— 建议写「本地笔记整理工具：粘贴文字生成结构化卡片、按主题归档、生成思维导图」，**不要**写「AI 自动生成」
- 若被要求补充资质，参考第 0 节的规避方案

**发布**：审核通过后，公众平台 → 版本管理 → 「发布」。发布后全量用户可见。

## 8. 用 CI 自动上传（可选：把 AppID + 密钥给我，我可以代跑）

如果你想让我以后直接帮你传版本，走官方 CI：

1. 公众平台 → 开发管理 → 开发设置 → **小程序代码上传** → 生成密钥并下载 `private.wxXXXX.key`
2. 把 **AppID + 密钥文件路径** 告诉我（密钥只在本机用，不上传任何地方）
3. 我执行：

```powershell
cd "D:\桌面\教学agent\温酱\miniprogram"
npm i miniprogram-ci --no-save
node -e "const ci=require('miniprogram-ci');(async()=>{const p=new ci.Project({appid:'YOUR_APPID',type:'miniProgram',projectPath:process.cwd(),privateKeyPath:'C:/path/private.wxXXX.key'});const r=await ci.upload({project:p,version:'1.0.0',desc:'知序 1.0.0',setting:{es6:true,minify:true}});console.log(r)})()"
```

> 注意：CI 上传同样受「代码上传密钥 IP 白名单」限制，可在后台关闭白名单或加上本机公网 IP。

## 9. 审核被驳回的常见原因（提前避开）

| 驳回理由 | 应对 |
|---|---|
| 类目与内容不符 | 只保留「笔记整理/效率工具」功能描述，AI 藏在设置里 |
| 涉及 AI 生成内容无资质 | 首版关闭云 AI，只留本地规则（`USE_CLOUD: false` 即纯离线） |
| 功能过于简单 / 页面空白 | 保证有示例卡片 + 完整「收集→归档→导图」闭环 |
| 存在诱导分享 / 拉新 | 不要做分享得额度之类 |
| 无隐私政策 | 后台「设置 → 服务内容声明」补一份隐私说明（我们只存本地/云数据库，不采集通讯录等） |

---

## 10. 上线后要改的东西

- `config.js` 里 `USE_CLOUD` 决定走云还是本地；两者数据不互通（云同步未开启时默认本地）
- 版本号在 `project.config.json` 不用改，上传时填
- 换 LLM 模型只改云函数环境变量，不用重新发版
