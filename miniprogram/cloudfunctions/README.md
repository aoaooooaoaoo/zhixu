# 云函数说明

三个云函数，都在「微信开发者工具 → 右键目录 → 上传并部署：云端安装依赖」。

| 云函数 | 作用 | 是否必需 |
|---|---|---|
| `analyze` | 文本 → 知识卡片（调用 LLM，key 只在云端） | 只有开启 AI 才需要 |
| `resolve` | 链接 → 标题/描述/正文（含 SSRF 防护） | 只有「读取链接」才需要 |
| `inbox` | 分享收件箱（云数据库集合 `inbox`） | 可选，小程序端 UI 二期接 |

## 环境变量（云开发控制台 → 云函数 → analyze → 配置）

| 变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `WJ_LLM_API_KEY` | 是 | — | 模型 key |
| `WJ_LLM_BASE_URL` | 否 | `https://maas-api.cn-huabei-1.xf-yun.com/v2` | OpenAI 兼容接口地址 |
| `WJ_LLM_MODEL` | 否 | `spark-x2.6-4b` | 模型名 |
| `WJ_LLM_EXTRA_BODY` | 否 | — | JSON 字符串，合并进请求体，例如 `{"thinking":{"type":"disabled"}}` |

同名变量也兼容网页版的 `RP_LLM_*`（会自动回退）。

## ⚠️ 超时时间必须改

云函数默认超时 **3 秒**，模型根本来不及返回，每次都会静默降级成本地规则。
在「云开发控制台 → 云函数 → analyze → 配置」把**超时时间改成 60 秒**；`resolve` 建议 20 秒。

## 数据库集合

`inbox` 集合权限选「仅创建者可读写」。`cards` 集合当前版本用不到（数据在本地）。

## 安全约定

- 任何 key / token **不要写进小程序前端代码**，只放云函数环境变量
- `resolve` 已拒绝本机、内网、保留地址（SSRF 防护），不要为了调试去掉
